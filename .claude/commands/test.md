Lance la suite de tests complète avec `npm test`.

1. Exécute `npm test` et capture la sortie complète.
2. Si tous les tests passent, confirme avec un résumé court (nombre de tests, durée).
3. Si des tests échouent :
   - Liste chaque test en échec avec le message d'erreur
   - Lis le fichier de test correspondant et le code source testé
   - Propose un fix précis pour chaque échec
   - Demande confirmation avant d'appliquer les fixes
